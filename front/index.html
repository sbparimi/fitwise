FAQ

Clear answers before you start

Do I need an account?

No. You can build, edit, check and export a resume without creating an account. Your working resume is saved in this browser. Optional cloud sync is separate.

Does the ATS score guarantee that my resume will pass?

No. Fitwise runs deterministic checks for common formatting, structure, readability and keyword issues. It is not integrated with or certified by Workday, Greenhouse, Lever, iCIMS, Taleo or any employer ATS. Always review the employer's application requirements.

What happens to my resume when I run a check?

The resume is read and analysed in your browser. When you run a scan, Fitwise stores the report and a generic file-type label for up to 30 days so the share link can reopen it. Your original file name, resume text and job description are not stored.

Which file types can I use?

The builder and checker accept PDF, DOCX and TXT files up to 10 MB. You can also paste resume text directly.

Can I edit the exported resume later?

Yes. Export to DOCX to continue editing in Microsoft Word or another compatible editor. PDF is suitable for sharing and applications that request PDF.
